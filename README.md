# Quiz Game CLI

A beginner-friendly Python command-line quiz game that asks multiple-choice questions, checks answers, keeps score, and displays the player's final result.

## Features
- Displays multiple-choice questions.
- Accepts answers from the player.
- Checks whether answers are correct or wrong.
- Keeps track of the player's score.
- Displays the final score.

## Technologies Used
- Python 3

## How to Run

```bash
python3 quiz_game.py
```
